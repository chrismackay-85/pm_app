# Pattern PM

Kanban board and Salesforce CRM rollout roadmap, built with Next.js. Client-rendered, no backend — state persists to the browser's local storage.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Testing

```bash
npm run test       # unit tests (Vitest)
npm run test:e2e   # end-to-end tests (Playwright)
```
